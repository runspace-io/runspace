02 / BOUNDARIES

Connected does not mean centralized.

Runspace coordinates access to systems that already own your code, data, and agent sessions. It does not need to absorb every secret or transcript.

CHANNELS

Shared context stays readable.

Discussion, decisions, connected resources, tasks, and published artifacts remain available to the workspace.

OWNER DEVICE

Private work stays private.

Agent prompts, raw transcripts, local paths, terminal output, and native credentials remain with the person running the work.

RESOURCE GRAPH

Systems stay connected by reference.

Teams and permitted agents discover resources and provenance without copying the underlying provider data into Runspace.

CHAT-SCOPED AUTHORITY

Share control of the work—not blanket access to a computer.

  • Viewer · see task and artifacts
  • Contributor · add task input
  • Operator · control task state
  • Approver · resolve access requests

03 / WORKFLOW

Work privately. Publish deliberately. Act together.

The channel keeps the durable team record without turning every conversation into a model prompt or every private session into shared noise.
